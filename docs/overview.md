# 경희대 키우기 — 프로젝트 개요

> 2026 KHU AI Challenge 참가 프로젝트 / 작성일 2026-10-09

## 1. 프로젝트 개요

**경희대 키우기 (KHUminicate)** — 경희대 국제캠퍼스 민원·제안 플랫폼 (픽셀아트 스타일)

- 목적: 민원 접수·처리 과정의 번거로움 해소, 더 나은 경희대 만들기
- 팀 구성: 3인 / 부문: AI 문제해결 솔루션

### 핵심 기능

**1) 민원 접수**
- 국제캠퍼스 픽셀아트 지도에서 문제 위치를 클릭 → 사진·동영상·설명 첨부해 접수
- AI가 담당 부서를 판단해 전달, 해결 완료 시 접수자에게 알림
- 장소와 무관한 행정 민원은 상단 채팅으로 접수 (AI가 동일하게 분류)

**2) 건의사항 접수**
- 별도의 가상 캠퍼스 지도에서 "이런 경희대였으면 좋겠다" 아이디어 제안
- AI 이미지 생성으로 비포·애프터 시각화
- '의견 전달하기'로 좋은 아이디어를 학교에 전달

**3) 게임 요소**
- 해결된 민원·채택된 제안이 쌓일수록 캠퍼스 '성장 게이지' 상승

## 3. 개발 기능과 우선순위

| 우선순위 | 기능 | 구현 방법 |
|---|---|---|
| 1 | 픽셀아트 캠퍼스 지도(민원용) | 건물별 클릭 영역 지정 (React + Canvas / 이미지맵) |
| 1 | 위치 기반 민원 접수 | 지도 클릭 → 건물 자동 입력 폼(사진·동영상·설명), 파일은 Supabase Storage |
| 1 | AI 부서 자동 분류 | 민원 텍스트 + 건물 → ChatKHU → 부서·요약 JSON. **분류 로직은 다른 팀원 담당** |
| 1 | 민원 DB/백엔드 | Supabase, 상태 관리(접수 완료 → 해결 중 → 해결 완료) |
| 1 | 직원(부서) 화면 | 부서별 민원 목록 + 상태 변경 — 시연 필수 |
| 2 | 처리 완료 알림 | 상태 변경 시 앱 내 알림 |
| 2 | 성장 게이지 | 해결 민원·채택 제안 수로 계산 |
| 2 | 채팅 민원 접수 | ChatKHU 대화로 정보 수집 → 같은 분류 로직 |
| 3 | 건의사항 가상 지도, AI 비포·애프터 이미지, 의견 전달하기 | |

형태: 웹앱(React). 설치 없이 링크로 시연, 모바일에서도 열림.

## 4. 디자인

- Claude Design으로 만든 디자인 사용 (내보낸 결과물은 `design/` 폴더)
- 하나의 웹앱에서 로그인 역할에 따라 **민원인(모바일 412×917)** / **직원(데스크톱 1440px, /admin)** 화면 분기, 같은 디자인 시스템 공유
- 16비트 게임 맵 스타일 픽셀아트 지도, 경희대 크림슨 레드 + 잔디 초록·하늘 + 민트(주요 CTA)
- 픽셀 폰트는 로고·제목·버튼에만, 본문은 한글 산세리프
- 공통 상태 배지 3단계: 접수 완료 → 해결 중 → 해결 완료
- 민원인 화면은 픽셀 게임 느낌, 직원 화면은 사무적인 느낌. 직원 대시보드에 캠퍼스 지도는 불필요

### 시연 시나리오

민원인이 지도에서 위치 선택 → 채팅으로 접수 → 직원 민원함에 AI 분류된 민원 도착 → 직원이 확인·해결 완료 처리 → 민원인 '나의 활동'에 해결 완료 알림.
시연용으로 우측 상단에 [민원인 / 직원] 보기 전환 토글을 둔다.
